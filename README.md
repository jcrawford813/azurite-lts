# Azurite LTS Image

This is an azurite image based on CentOS to give a stable workstation-like base for a desktop image. To enhance functionality, I have layered on:

- EPEL
- Plasma 6
- Flatpak

This will likely not support bleeding-edge hardware, but will supply the security and stability while still being reasonably cutting edge in userspace.
